## 🎯 Core Concept
Este repositório centraliza minha evolução lógica e prática diária. Funciona como um diário de bordo técnico para consolidar estudos que não exigem grandes estruturas, focando em:

* **Academic:** Resoluções de listas e projetos universitários.
* **Practice:** Desafios de lógica e fixação de sintaxe.
